Ταξίδι στην Παράδοση

Χαμηλής πιστότητας σκαριφήματα διεπαφής για έλεγχο πριν την υλοποίηση. Κάθε όψη είναι αυτόνομο αρχείο HTML που μπορείτε να ανοίξετε απευθείας. Κανονικό περιεχόμενο είναι ενδεικτικό (dummy data) — η πλήρης λίστα περιοχών, κατηγοριών και ρυθμών έρχεται από τον επιστημονικό υπεύθυνο.

Δημόσιες σελίδες
/

Αρχική σελίδα

Τρεις στήλες: φίλτρα αριστερά, χάρτης στο κέντρο, πάνελ τραγουδιού δεξιά, παραρτήματα κάτω. Σύμφωνα με το σκαρίφημα σας.

Κύρια διάταξη /songs/[code]

Σελίδα τραγουδιού

Αυτόνομη όψη για μόνιμη παραπομπή: τίτλος, στίχοι (κεντραρισμένοι), ήχος, πηγές, παραπομπές σε άλλα τραγούδια.

Permalink /about · /methods

Επιστολή / Μέθοδοι

Πρότυπο εκδοτικών σελίδων. Επικεφαλίδα μοτίβου, lede, σώμα κειμένου, υποσημειώσεις, rule-dotted.

Σύνταξη
Διαχείριση (admin)
/admin

Ταμπλό διαχείρισης

Σύνοψη: πλήθη, πρόσφατες αλλαγές, εκκρεμότητες (π.χ. τραγούδια χωρίς ήχο), γρήγορες ενέργειες.

Κεντρική /admin/songs

Λίστα τραγουδιών

Πίνακας με φίλτρα, αναζήτηση, bulk actions, εκκρεμότητες με κουκίδες (ήχος / στίχοι / κατηγορία).

Κατάλογος /admin/songs/[id]

Επεξεργασία τραγουδιού

Έξι καρτέλες: Βασικά, Κείμενα, Κατηγορίες, Πηγές, Ήχος, Παραπομπές. Ενεργές φόρμες Markdown.

Φόρμα /admin/regions

Επεξεργαστής περιοχών

Λίστα περιοχών + χάρτης με εργαλείο σχεδίασης πολυγώνων (leaflet-geoman placeholder). Audit trail κάτω.
